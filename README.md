# Shivam Shakya — Developer Portfolio

A responsive, animated dark portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal.

## Before publishing
Update the placeholder links and details in `src/App.jsx`:
- `shivamshakya.dev@example.com` → your real email
- GitHub profile/repository URLs
- LinkedIn profile URL
- Project demo URLs
- Confirm experience dates and wording
- Add your actual resume PDF to `public/resume.pdf` and add a resume download link if needed.

## Build for deployment
```bash
npm run build
```
The production output will be in `dist/`. Deploy the project to Vercel by importing the GitHub repository; Vercel will detect Vite automatically.
